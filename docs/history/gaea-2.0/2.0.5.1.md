# 2.0.5.1

A small but important build with some useful new features and bug fixes.

* Nodes now show build time on the surface. Can be disabled in Options.
* Updated Statistics dialog in Project Menu with expanded graphs to find bottlenecks.
* Proxy options for license server.
* Added option to securely share diagnostic logs publicly via Log Codes.
* FIX: Rare crash could occur when connecting nodes.
* FIX: Crash diagnostics improved.
* FIX: Sporadic license activation issues.
* FIX: Sporadic License Server communication issues.
