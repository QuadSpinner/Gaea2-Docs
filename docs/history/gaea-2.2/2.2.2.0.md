# 2.2.2.0

#### New in 2.2.2.0

* Property Area now shows node commands in a new toolbar.
* Node Reversion commands now available near Modifiers stack.
* Experimental ColorSpace option in Build Settings for 8/16-bit files.
* FIX: In rare cases, preferences file could get corrupted.
* FIX: Unreal node could crash if 16K resolution was used.
* FIX: Gaea2Houdini internal stability fixes.
* FIX: Gaea could crash on startup if monitors were changed.
* Minor internal fixes to improve file format size.
