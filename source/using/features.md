## Terrain creation and realism

* Node-based Infinity Graph for building complete terrain recipes, from first shape to final outputs.
* Extensive node library covering generators, shaping, masking, filtering, simulations, surfacing, utilities, and exports.
* Real-world landform simulations, built around erosion workflows like [Erosion](@understanding-erosion).
* Surface and material workflows for believable terrain finish, including [Crafting the Surface](@crafting-the-surface).
* Color workflows from procedural to photographic, including [SatMaps](@working-with-satmaps).

## Build, export, and production pipeline

* End-to-end [Build and Export](@build-and-export) workflow for repeatable output generation.
* Detailed build diagnostics and outputs via [Build Reports](@build-reports).
* Large-world production via [Tiled Builds](@tiled-builds).
* Focused high-resolution production with [Regions](@using-regions).
* Mesh pipelines for engines and DCCs via [Mesh Exports](@mesh-exports).
* Element-focused exports for downstream compositing and look-dev via [Exporting Elements](@exporting-elements).

## Speed, iteration, and convenience

* Non-destructive finishing controls with [Modifiers](@using-modifiers).
* Rapid variation systems through [Mutations](@creating-mutations).
* Predictive workflow assistance via [Learning and Predictive System](@learning-and-predictive-system).
* Practical approaches for building complex terrains via [Elaborate Terrains](@elaborate-terrains).
* Tools and habits for scaling big projects via [Managing Graphs](@managing-graphs).
* Cleaner complex graph wiring patterns using [Portals](@portals-introduction).

## Automation and pipeline integration

* Headless, high-resolution batch building with [Build Swarm](@build-swarm).
* Saved, repeatable production presets through [Profiles and Batch Builds](@profiles-and-batch-builds).
* Full CLI automation for farms and pipelines via [Command Line Automation](@command-line-automation).
* Operational CLI for activation, proxy, safe mode, and diagnostics via [Command-line Interface](@command-line-interface).
* Automation-friendly filename and path control using [Managing Input and Output](@managing-input-and-output).

## Parametric control and power-user extensibility

* Centralized controls that can drive many properties via [Variables](@variables).
* Per-control value shaping, remapping, and logic using [Expressions](@expressions).
* Scriptable procedural construction inside graphs with [Math Node](@math-node).
* A structured entry point for advanced control systems via [Scripting and Expressions](@scripting-and-expressions).

## Reliability, troubleshooting, and production readiness

* Bake and cache strategies for large builds using [Baking Nodes](@baking-nodes).
* Project-wide inspection and cleanup tools via [Data View](@data-view).
* Built-in diagnostics and benchmarking via [Diagnostics](@diagnostics).
* Optional CPU-only operation for compatibility and debugging via [CPU Only Mode](@cpu-only-mode).
* Common pitfalls and quick fixes collected in [Common Errors](@common-errors).

## Import, formats, and interoperability

* Broad interchange support for practical pipelines, documented under [File Formats](@file-formats).
* Real-world terrain ingest workflows starting with [Importing Terrains](@importing-terrains-introduction).
* Mesh ingestion workflows for hybrid pipelines via [Importing Meshes](@importing-meshes).

## Reuse and packaging

* Reusable mini-graphs as single nodes with [Macros](@macros).
* Macro creation workflow and packaging through [Building Macros](@building-macros).
* Guidance for building maintainable, shareable macro libraries via [Macro Best Practices](@macros-best-practices).
