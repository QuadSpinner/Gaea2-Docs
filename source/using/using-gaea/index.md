# Using Gaea

The Using Gaea section covers the practical workflows that turn a terrain graph into a finished asset. These pages focus on how the major systems work together: shaping the initial landform, applying erosion and simulations, creating masks and textures, managing larger graphs, and preparing the final build.

Start with @understanding-erosion and @crafting-the-surface when you are building the terrain itself. Move to @colorizing-and-textures once the landform needs masks, data maps, and color outputs. Use @managing-graphs and @baking-nodes when the project grows large enough that organization and iteration speed become important.
