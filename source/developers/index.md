# Developer Overview

This section is for technical users building pipelines, automation, or extensions around Gaea. It covers command-line workflows, bridge development, macros, expressions, and SDK-oriented material.

Start with Automation if you are scripting builds, license tasks, or bridge workflows. Use Extensibility when you want to create reusable tools, expose controls, or build on the TOR platform.
