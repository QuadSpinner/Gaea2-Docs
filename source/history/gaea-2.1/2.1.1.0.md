# 2.1.1.0

## **Gaea 2.1.1 – Key Highlights**

* **Revamped Variable System** – Improved UI, expanded support for all variable types, and a more flexible architecture.
* **New Math Node Editor** – Feature-rich editor with convenience tools for easier calculations and logic.
* **Enhanced Cartography Node** – Create even better maps with these new features.
* **New Shade & Patterns Nodes** – Generate simple lighting effects and create line, dot, and engraving patterns.
* **Improved File Save System** – Enhanced reliability to prevent data loss and corruption.
* **Several important fixes** - Improved stability from several key bug fixes based on user feedback.

See Variables and Expressions in action on [our YouTube Channel](https://gaea.app/vid-variables)

***

#### **Variables & Workflow Improvements**

* **Revamped Variable UI** – Improved design for better usability.
* **Advanced Variable Architecture** – New system for greater control and flexibility.
* **Expanded Variable Support** – Now supports all remaining variable types.
* **Enhanced Variable Editing & Handling** – More intuitive and efficient.
* **Expressions** – Now fully functional for all Float and Int properties.
* **More Undo Opportunities** – Expanded undo support for normal workflows.

#### **Nodes & Rendering**

* **New Shade Node** – Generates simple lighting effects for **cartography and visualization**.
* **New Patterns Node** – Create **line, dot, and engraving patterns** for stylized terrains.
* **Cartography Node Overhaul** – Improved **contour control** and **new color palettes**.
* **Cartography Shade System Update** – Now handled by the new **Shade Node**.
* **Math Node Update** – Upgraded with a **feature-rich editor and convenience tools**.
* **Dilate Node Enhancement** – Added **curve support** for better control.
* **Unreal Engine Export** – New option to **disable texture map resizing**.

#### **Performance & UI Enhancements**

* **Adaptive Timers (Experimental)** – Faster node feedback for improved responsiveness.
* **Streamlined About Dialog** – Cleaner, more informative UI.
* **Improved Diagnostics & Console Output** – Better error reporting and license activation via CLI.
* **Property Binding Menu** – Enhanced visuals for a smoother experience.
* **Missing VC++ Warning** - Portable install will warn if C++ redistributable is missing.

#### **File Management & Licensing**

* **Floating License Management** – New option to **permanently release** a floating license.
* **Thumbnail Storage Options** – Choose to store thumbnails **centrally** instead of next to the file.
* **Save System Improvements** – More **robust handling of file saves**.
* **File Size Estimation** – Now available in the **Bake Menu**.
* **Build Command-Line Preview Fixes** – Prevents crashes if `ESC` is pressed.
* **Status Bar Warning** – Notifies users if the highest-rated compute device is disabled.
* **Hybrid Build Error Messaging** – More accurate feedback.

#### **General Fixes**

* **Critical Fix for Stale Caches** – Resolves long-standing cache handling issues.
* **Improved Save System Stability** – Ensures safer project saves.
* **Fixed Memory Leak in Data View UI** – Prevents excessive memory usage.
* **Enhanced Readouts in Stats Data View** – Displays **project information** when no node is selected.
* **Color Picker Bug Fixed** – Changing **Hue** now updates the color correctly.
* **Color Editor Fix** – Numeric entry now **properly recognizes values**.

#### **Node & Processing Fixes**

* **LightX Node Fix** – Secondary outputs are now correctly treated as masks.
* **Large Blur Radius Fix** – Prevents rare artifact generation.
* **Volcano Example Load Fix** – Ensures successful loading.
* **Houdini Export Timeout Fixed** – Now processes **8K terrains** reliably.
* **Pockmarks Node Fix** – Now respects **scale range**.
* **Dilate Node Fix** – Prevents data contamination from previous nodes.

#### **UI & Workflow Fixes**

* **Prevented Accidental Modifier Reordering** – Eliminates unintended dragging.
* **Fixed Bookmarked Node Crash** – Prevents errors if a bookmarked node is missing.
* **Dropped File Behavior Fix** – Closing the **Start Window** when dropping a file now works as expected.
* **File Open Warnings** – Now alerts users when changing files while nodes are actively building.
* **Improved License Activation for IT Admins** – Critical fix for enterprise setups.
* **Hide License Button When Licensed** – Onboarding UI now correctly reflects licensing status.
