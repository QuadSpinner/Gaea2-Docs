# 2.0.5.0

* Height Picker and Measurement Tools added to 2D viewport.
* Added Automatic Resolution option to Unreal node.
* Added option in Diagnostics to run Gaea in verbose mode.
* FIX: Some users were prevented from accessing all properties of a node.
* FIX: HSL node would not recognize color input.
* FIX: Perlin and Voronoi gizmos would not behave correctly.
* FIX: DistanceRT node could show incorrect results sporadically.
* FIX: Some RGB files would be loaded incorrectly with 4 channels.
* FIX: Snap to Ports improved.
* FIX: Verbose command line argument would not be honored.
* FIX: Improved hardware loading and validation at startup.
* FIX: Dependency package with security vulnerability upgraded.
* Improved diagnostics collection to understand the system state.
* Several internal improvements and optimizations.
