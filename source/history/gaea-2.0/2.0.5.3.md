# 2.0.5.3

* Insert node command added to Connection context menu.
* Classic Wizard node ported from Gaea 1 (Experimental).
* Option to include existing Snow in Dusting node when connected to Snow node.
* New draft Documentation now available via the Help menu.
* FIX: Reset Node did not work.
* FIX: Regression in Snow node's Directional Melt.
* FIX: Labels in Editor could become empty.
* FIX: Corrupt thumbnail could crash Start screen.
* FIX: Range Slider did not accept entry in meters.
* FIX: Rare graph setup error when opening a file.
* FIX: Color nodes could misbehave if expected heightfield was replaced with a color map.
* FIX: Automation Command Line preview improved.
* FIX: Autosave menu has a dropdown glyph for consistency.
* FIX: Rare crash could occur when node creates an undo revert point.
* FIX: Solved a resolution limitation issue in Houdini.
* Several internal fixes.
