# 2.0.5.4

* Added Search Results limit in Options.
* Added Grid Snap Size in Options.
* Added menu item in File menu to open Start Window.
* Added menu item in Help menu to check for updates.
* Improved text entry and Nudge features in Range Sliders.
* Direction arrows added to Navigate menu for better cognition.
* Mutate command added to Node menu.
* Experimental Expression editor added to all Sliders via the editor menu. Use formula `x` to refer to the current value, for example `x * 0.5`.
* Graph Toolbar menu commands now available via Graph menu as well.
* FIX: Mixer masks would not be accessible except via Data Extractor.
* FIX: Normals node could contaminate previous node.
* FIX: Clip adjustment was broken.
* FIX: Show/Hide graph was broken.
* FIX: Critical bug that could mark multiple nodes as underlays when loading older file.
* FIX: Hotkeys could intercept typing in the Build panel.
* FIX: Build tab would not show the savable filename.
* FIX: Ignore sub-elements of a group when snapping to items.
* FIX: Autolevel Masks or Save in 2D viewport could cause a crash.
* FIX: Toggle Engine menu command was broken.
* FIX: MultiMix could suspend engine if only one node was selected.
* FIX: Reset command in Node menu now accepts multiple selected nodes.
* FIX: Autolayout would not create an undo entry.
* FIX: Replacing node with a Preset could cause a crash.
* FIX: Node context menu revised for multiple node selection.
* Added asynchronous logging for improved performance.
* Several internal fixes.
