# 2.0.5.2

* Added Passive Caching when Engine is Idle.
* Added Repair File command to the File menu. It can attempt to recover files with minor issues.
* Added shortcut `V` to toggle flat preview of current node.
* FIX: Lock Preview and Underlay buttons in Data View Build Tab did not select node.
* FIX: Underlay icon would not refresh in the Data View Node Tree.
* FIX: Rare crash when a node connection was dragged and dropped on the node itself in a specific way.
* FIX: Internal color conversion code could fail to render color maps in some situations.
* FIX: Gamma (color), HSL, and other color nodes were affected by the aforementioned issue.
* FIX: Duplicated node with Modifiers could fail in some situations.
* FIX: Corrupt or missing Baked Data should not prevent files from being loaded.
* FIX: Invalid nodes should not be allowed to be baked.
* FIX: Improved error-handling for how Baked Data is loaded and validated in rare situations.
* FIX: Added redundant checks to prevent failed Bakes from being saved to disk in partial form.
* FIX: Error during baking process should invalidate.
* FIX: Error saving PNG or TIFF with Alpha channels.
* FIX: Splat node would force Alpha channel use even when the Alpha channel port was not connected.
* FIX: Rare crash when using Search if a Preset was corrupted.
* FIX: Potential crash in Whorl fixed.
* FIX: Water nodes would not render if there was no water generated.
* FIX: Build Time readout on Node surface would conflict with other icons.
* FIX: Failure to open a valid file with the error "The given key was not present in the dictionary".
