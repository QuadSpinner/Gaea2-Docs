# 2.0.2.2

* Added option to select which Monitor Gaea should start on.
* Further improvement to Nvidia device memory sharing for 4K builds.
* Prevent "Invalid User Key" error when validating licenses.
* Further improvements to prevent crashing on startup.
* Allow dragging Welcome window.
* Fixed a bug where Gaea could exit after validating a license.
* Added option for Verbose logging.
