# 2.0.2.0

### New

* Major fix for Nvidia drivers that could prevent Gaea from starting.
* Major fix for Nvidia driver issue that could slow down processing significantly.
* New onboarding/welcome dialog.
* Rivers output added to Rivers node for better masking.
* Snap connections to available Ports (can be disabled in options).
* Difference modifier added.
* Strong modifier added. Similar to the Gaea 1 Log modifier.
* New shortcut `M` to open Modifiers menu.
* New shape options added to RockNoise.
* Notification when Height port for Underlay-dependent nodes is not connected.

### Improved

* Gaea uses fewer GPU resources when idle.
* HydroFix node is now available.
* Height Data Map defaults improved for better usage.
* Show stark visuals upon Engine Suspension.
* New styles and defaults for Mountain node.
* Erosion2 simulation duration can now be double.
* Tree Node simplified for easier control.
* Contours node output improved.
* Options Dialog improved.
* Diagnostics data improved for better issue detection.
* Improved build confirmation before starting build.
* Right-click Refresh and Mutate buttons on toolbar for "All" options.
* LazyBoy menu shortcut moved to `F1` to avoid conflict to Suspend Engine.
* Diagnostics now saves Device Benchmark to desktop.
* Connect Cursor removed based on user feedback.
* Notes can now be added to Groups.
* Added context menu to rename Groups.
* Added filename in title bar for better compatibility with ShareX and other screenshot apps.
* Allow CLI Build Swarm to be non-modal so Gaea UI can be closed to save resources.
* Enforce 4K resource conservation in Viewport by default

### Fixed

* Sliders would not accept entry in Meters.
* Constant would break incoming node.
* Terrain height ratio was not maintained when using custom terrain scales.
* Surface node icons were missing.
* Authorize and Start dialogs were both On Top causing visibility issues.
* Dilate node would show incorrect parameters.
* Folders were not organized properly in Standard build with Tiled output.
* RockNoise would draw incorrectly.
* Searched node would create connected to incorrect parent node.
* Removed a critical bug in edge masking that affected several nodes.
* Error in node tooltip would not be cleared.
* Slider curve markings made more accurate.
* Duplicated nodes did not have Modifiers.
* Duplicated nodes did not have certain properties.
* Sediments would render incorrectly.
* Undo text on modifier changes was incorrect.
* Installer caused a file associated error on portable installations.

### MISC

Cartography has been temporarily removed. It is coming back as a Family of nodes with extensive map-making abilities.
