# 2.2.4.0

#### New in 2.2.4.0

* New Seed control with memory slots for easier randomizations.
* Classic Toolbox is back! Switch between Menus and Panel modes in the Toolbox.
* Additional pinning and highlight options in Toolbox.
* Option to allow sliders to accept edited values when clicking outside.
* Gaea now remembers your preferred Toolbox size and Data View collapsed state.
* Improved handling of caches and recycling cache memory.
* Experimental Compact Interface style in Options' Experimental tab.
* New Area Mask mode in Trees node.
* FIX: Crash when loading floating viewport.
* FIX: Build Swarm should revert to default build path when given path is denied access.
* FIX: Tooltip text did not wrap.
* FIX: Status bar could break when showing node errors.
