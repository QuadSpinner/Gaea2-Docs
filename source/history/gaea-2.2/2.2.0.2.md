# 2.2.0.2

## New in 2.2.0.2

* Allow saving current build cache as build output.
* Pixelate now has Autosize and Antaliasing options.
* Added UDIM file naming support for Tiled Builds.
* Warning for older files with corrupted elements.

## Fixes in 2.2.0.2

* FIX: Crucial fix for Tiled Builds that affected some users.
* FIX: Shrubs was not available for some users.
* FIX: Trees' Random was not behaving properly.
* FIX: Bad paths in Custom Paths could crash Gaea.
* FIX: Improved notifications for SwarmHost.
* FIX: SwarmHost did not work for Gaea Professional.
* FIX: Markdown links did not work.
* FIX: Setting the same resolution again should not force a rebuild.
* FIX: Silent argument was not honored in some instances.
* FIX: Improved recovery of obsolete Save Definitions in older files
