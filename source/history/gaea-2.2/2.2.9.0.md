# 2.2.9.0

## New in 2.2.9.0

* Halftone: New maps and posterization capability.
* FIX: Gaea could crash if Mesher is bypassed.
* FIX: Gaea could become unstable if Output nodes were baked.
* FIX: Crash when creating excessive tabs.
* FIX: A rare bug in Mesher could crash Gaea.
* FIX: Updates were stored in the root folder instead of Updates.
* FIX: Gizmo did not work in old style Crater.
* FIX: Improved visual feedback when using double-click to connect nodes.
* FIX: Duplicated nodes did not contain original portals or connections.
* FIX: SatMap Clipping slider was behaving incorrectly.
* FIX: Unnecessary Validation Failed message on using Build tab.
* FIX: Viewport AO and Shadows checkboxes were broken.
* FIX: Dropping a node on another node connects them.
* FIX: Dropping nodes could create extra copies in some cases.
* FIX: Some old Gaea 1 Halftone maps were broken and were removed.
