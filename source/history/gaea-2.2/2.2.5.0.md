# 2.2.5.0

#### New in 2.2.5.0

* Onboarding experience improved.
* Seed textbox can be right-clicked to show memory menu.
* FIX: Toolbox menus would incorrectly hide.
* FIX: Several improvements for Compact UI and responsive layouts.
* FIX: Slider value could get cut off on small screens.
* FIX: Several controls did not scale well for smaller screens.
* FIX: Mesher did not export Adaptive Tris output for some users.
* FIX: Unselect node when switching tabs.
* FIX: Draw window toolbar was missing tooltips.
* FIX: Minor improvements in item snapping.
* FIX: Meshify and Transform3D render on CPU.
* FIX: Hot mask gradient was not available in Options window.
* FIX: Incorrect default mask gradient was being set through Options.
* FIX: Draw dialog is now modal to avoid accidents.
* FIX: Bomber could fail when switching RGB to non-RGB inputs. 
* FIX: Locked 2D viewport would behave incorrectly when switching ports.
