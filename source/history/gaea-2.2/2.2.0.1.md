# 2.2.0.1

#### New in 2.2.0.1

* New Geographic lighting mode for LightX node.

#### Fixes in 2.2.0.1

* FIX: Options dialog could crash if options were corrupted.
* FIX: Examples Files could not be used properly in a write-protected folder.
* FIX: Rivers could create incorrect surface.
* FIX: Mesher incorrectly mentioned MeshWarp and not TextureBaker.
* FIX: Tile Suffix was not honored.
* FIX: SwarmHost should not handle file errors silently.
* FIX: Range Sliders would not reset to node's default values.
* FIX: Outcrops default values were incorrect when reset.
* FIX: Presets could cause a crash if saved in all lowercase name.
* FIX: Gizmos for several nodes would behave incorrecty.
* FIX: Duplicated nodes could incorrectly share Save Definitions.
* FIX: Added SaveDefinition de-coupling code for safety.
* FIX: Build filename did not save on TAB.
* FIX: Build Swarm did not show proper error if path could not be built.
* FIX: Show proper error message if Gaea 1 key is loaded.
* FIX: Show warning if there are duplicate build filenames.
* FIX: Setup should download newer .NET 8 distribution.
