# 2.2.6.0

#### New in 2.2.6.0

* Improved navigation hints for new users.
* Added Insert Chokepoint in connection context-menu.
* Show undo description when performing an undo.
* Added Reset command for each page in Options.
* FIX: Baked nodes would not export.
* FIX: Mouse sensitivity could not be set for some users.
* FIX: Improved save prompt when closing a modified file.
* FIX: Several internal cleanups and fixes in graph behavior.
* FIX: Renaming a node could crash when portal was null.
* FIX: Artifact Explorer crash on load.
* FIX: Default folders would not be created in some situations.
* FIX: Tiled Builds - report and other artifacts were not stored in the root folder.
* FIX: Tiled Builds - Copy of Terrain file was not made.

**SECURITY UPDATES**

* Unity CVE-2025-59489 security vulnerability patched.
* Potential vulnerability in ImageMagick library patched.
