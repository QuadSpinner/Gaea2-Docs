# 2.2.3.0

## New in 2.2.3.0

* Clear warnings in Node Properties when a node fails.
* Node Properties menu command to bind all properties.
* Viewport Toolbar reorganized for better access to Viewport Elements, Screenshots, and more.
* Screenshot options moved to Preview menu.
* Overlay options now available in Viewport toolbar.
* Overlay options are now saved in the project.
* FIX: Build would crash if a baked node was marked for export.
* FIX: Baked nodes could not be exported.
* FIX: Transform, Bomber marked as "Requires Baking".
* FIX: Bridge commands language changed from software specific to generic.
* FIX: License Server address option now accepts all common URL formats.
