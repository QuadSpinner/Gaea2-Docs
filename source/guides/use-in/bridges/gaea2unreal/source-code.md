# Source Code

The source code for the plugin can be found at: [Gaea2Unreal Github Repo](https://github.com/QuadSpinner/Gaea2Unreal)

The `main` branch contains the latest version. Any work-in-progress can be found in a `dev` branch while, past releases can be found in numbered version branches such as `UE-5.3`.

Issues should be opened only for the source code. For usage or other issues, you should contact [QuadSpinner Tech Support](https://quadspinner.com/support).
