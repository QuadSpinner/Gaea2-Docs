# Gaea2Unreal

Use Gaea2Unreal, specifically the Gaea Landscape Importer, to easily import a Gaea terrain, color maps, weight maps, and masks in Unreal Engine 5 with a single click.

Importing terrains into Unreal Engine can be a complicated process, especially when dealing with various scales. Gaea2Unreal aims to make this an easy, seamless experience for you.

## Download

Download the latest plugin from [Github Releases](https://github.com/QuadSpinner/Gaea2Unreal/releases).

# Note

Gaea2Unreal is a free, open-source companion plugin we provide as a convenience to Gaea users. It is not a paid product, and it is not part of Gaea's core terrain-building pipeline.

We do our best to keep it updated alongside Unreal Engine releases, but Unreal updates can sometimes introduce breaking changes and move faster than we can immediately match.

For that reason, we also provide the full source code at no cost, so anyone who needs an urgent fix can make changes right away instead of waiting on our update cycle.
