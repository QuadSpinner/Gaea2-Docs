# Guides Overview

Use this section when you want practical, task-focused help. Guides are organized around production scenarios, integrations, and real workflows instead of individual interface panels or node reference pages.

If @home-user-guide explains how Gaea works, Guides explain how to apply Gaea to a specific production problem.

---

## Start Here

:::info
Use Guides when:

- you are moving a terrain into another application
- you are solving a workflow, scale, format, or output problem
- you are building a larger project and need practical production habits
- you want scenario-based advice rather than node-by-node reference
:::

## Main Areas

### Scenarios

Start with @scenarios when the question is about a production situation: large projects, workflow hygiene, mesh output, naming, baking, or common quality issues.

Useful starting points:

- @workflow for graph and output workflow habits
- @large-projects for splitting and managing heavier work
- @meshes for mesh-specific output considerations
- @common-issues for troubleshooting-oriented scenario notes

### Use in DCC Apps

Start with @universal-instructions when you need to move Gaea terrain into another tool and are not sure whether you need a mesh, displacement map, landscape, or bridge workflow.

Use app-specific pages when your target tool matters:

- @software-specific-instructions for DCC app guidance
- @engines for game engine-oriented workflows
- @bridges for dedicated bridge workflows
- @gaea2houdini for Houdini integration
- @gaea2unreal for Unreal integration

## Suggested Paths

If you are exporting for the first time, read @universal-instructions before choosing an app-specific guide.

If something looks wrong after import, start with @common-issues and then check the guide for your target app or engine.

If a project is becoming slow or hard to manage, start with @large-projects and @workflow before changing export settings.
