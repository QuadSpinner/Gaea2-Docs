# Your Custom Macros

Your installed custom Macros appear here as reusable nodes. These entries come from `.macro` packages installed in Gaea, so the exact list depends on your local Macro library.

Use this family when you want to:

- reuse a packaged graph as a normal node
- find a team, project, or personal Macro by name
- create an instance of a custom tool without opening its source graph

For reference on the native Macro instance node, see @macro. To define Macro inputs and outputs while authoring a Macro, use @macroport. For the full creation workflow, see @building-macros.
