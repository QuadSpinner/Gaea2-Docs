# Node Families

Browse the Gaea node library by family. Each family groups related processors so you can compare similar tools quickly and jump to the exact node you need.

Use this page when you know the kind of work you want a node to do, but not the exact node name yet.

## Choose a Family

| Family | Best starting point when you need to... |
| --- | --- |
| @primitive | Generate simple shapes, gradients, masks, patterns, noises, or reusable graph inputs. |
| @terrain | Create a large terrain base such as mountains, islands, ridges, dunes, craters, or volcanoes. |
| @modify | Reshape, filter, warp, clamp, sharpen, smooth, or clean up an existing terrain or mask. |
| @surface | Add visual surface character such as terraces, rocks, sand, stones, cracks, or stratified detail. |
| @simulate | Add natural process behavior such as erosion, snow, debris, water, trees, or vegetation. |
| @derive | Extract masks and supporting maps from height, slope, flow, curvature, normals, color, or surface structure. |
| @colorize | Build terrain color, split or merge channels, apply palettes, or weather color through terrain flow. |
| @output | Preview, render, bake, export, or prepare outputs for engines, DCC apps, and production pipelines. |
| @utility | Route data, organize graphs, compare inputs, manage masks, or add reusable graph logic. |
| [Macro](/reference/nodes/macro/) | Browse installed custom Macros that appear as reusable nodes in the graph. |

## How to Use Node Pages

Most node pages are designed for fast lookup first. A finished page should tell you what the node does, when to use it, what visual result to expect, and which properties matter most.

Some node pages include visual reference images in the foldout to show the intended result or comparison at a glance.
