# Surface Nodes

Surface nodes add terrain character, breakup, stratification, and material-like detail. Use this family after the main landform exists and you need the surface to feel rocky, sandy, layered, cracked, weathered, or more visually complex.

Start here when you need to:

- add rock, sand, stones, terraces, or surface breakup
- make a clean terrain feel less procedural
- build stratified or fractured terrain detail
- create surface patterns that respond to the existing terrain shape

Useful starting points:

- @terraces, @fractalterraces, @stratify, and @sandstone for layered forms
- @rockscape, @rocknoise, @outcrops, @stones, and @roughen for rocky character
- @sand, @distress, @craggy, @shatter, and @shear for breakup and erosion-like detail
- @bomber, @groundtexture, @pockmarks, @steps, and @grid for specialized surface structure
