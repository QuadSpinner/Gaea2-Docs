# EasyErosion

## When to Use It
Use EasyErosion when you need a simplified erosion workflow for quickly adding natural erosion effects.

## Visual Direction
Compare the same terrain before and after EasyErosion so the simplified erosion pass feels approachable instead of opaque. If you add a second visual, make it a stronger-vs-softer erosion comparison.
